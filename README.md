# 📚 OOP Lab Manuals — C#

A collection of Object-Oriented Programming lab tasks completed as part of the **BS Computer Science (Gaming & Animation)** program at **UET (University of Engineering and Technology)**.

All code is written in **C#** and covers core OOP concepts practiced through hands-on lab exercises.

---

## 🗂️ Repository Structure

| Folder | Description |
|--------|-------------|
| `lab1 tasks` | Introduction to C# — basic syntax, variables, and I/O |
| `lab2` | Control structures — conditionals and loops |
| `lab3` | Methods and functions in C# |
| `lab 4` | Classes and objects — defining and instantiating |
| `lab5` | Constructors, access modifiers, and encapsulation |
| `lab6` | Inheritance and method overriding |
| `lab8` | Polymorphism and abstract classes |
| `Lab9` | Interfaces and their implementation |
| `Lab10` | Advanced OOP concepts (SOLID principles / design patterns) |

> **Note:** Lab 7 is not included in this repository.

## 🚀 How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/abduu-codes/oop_manuals.git
   ```
2. Open any lab folder in **Visual Studio**.
3. Open the `.sln` or `.cs` file.
4. Press `F5` or click **Run** to execute.
